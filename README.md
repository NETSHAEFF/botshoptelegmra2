# Telegram Bot Shop (aiogram 3.x)

Полноценный Telegram-бот-магазин с FSM, SQLite и админ-панелью.

## Возможности
- Каталог товаров с inline-кнопками.
- Покупка с выбором способа оплаты.
- Автоматическая оплата через CryptoBot (инвойсы, проверка статуса, авто-доставка).
- Оплата Telegram Stars (официальные платежи Telegram).
- Полуавтоматическая оплата (реквизиты, чек, подтверждение админом).
- Админ-панель в Telegram и web-админка в браузере.
- Встроенная аналитика: запуски, просмотры, покупки, выручка, активность за 24ч/7 дней.
- Рассылка всем пользователям.

## Стек
- Python 3.10+
- aiogram 3.x
- SQLAlchemy 2.x (async)
- SQLite по умолчанию (можно заменить на PostgreSQL через `DATABASE_URL`)

## Установка
1) Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

2) Скопируйте и заполните `.env`:

```powershell
Copy-Item .env.example .env
```

3) Запустите приложение (бот + web-админка):

```powershell
python -m bot.main
```

## Инициализация данных
При первом запуске таблицы создаются автоматически.

Для примера можно создать демо-данные:

```powershell
python -m bot.database.seed
```

## Основные команды
- `/start` — приветствие + список товаров.
- `/admin` — админ-панель (только для `ADMIN_IDS`).

## Web-админка
- URL: `http://WEB_ADMIN_HOST:WEB_ADMIN_PORT/admin`
- Логин/пароль задаются в `.env`:
  - `WEB_ADMIN_USERNAME`
  - `WEB_ADMIN_PASSWORD`
  - `WEB_ADMIN_SECRET`
- На главной странице web-админки доступна статистика бота и последние события.
- При стандартном запуске `python -m bot.main` web-админка стартует автоматически.
- Отдельный запуск web (опционально): `python -m bot.web.main`

## Настройка оплаты
### CryptoBot
- Укажите `CRYPTOPAY_API_TOKEN` в `.env`.
- При необходимости включите тестнет: `CRYPTOPAY_TESTNET=true`.
- В админ-панели можно включать/выключать CryptoBot.

### Telegram Stars
- Работает через встроенные платежи Telegram (валюта `XTR`).
- В админ-панели можно включать/выключать Stars.
- Цена Stars считается от рублевой цены по курсу `STARS_RUB_RATE` (₽ за 1 ⭐).

### Полуавтоматическая оплата
- Настройте реквизиты в админ-панели.
- Пользователь отправляет чек, админ подтверждает оплату.

## Важные заметки
- Вступительное сообщение хранится в БД и редактируется через админ-панель.
- Контент товара — это текст/ссылка, который отправляется после оплаты.
- Фото товара хранится как `file_id` в БД и берется из сообщения Telegram.
- Цена в Stars хранится отдельно (`price_stars`); если не задана, используется цена в рублях.
- Если хотите PostgreSQL, установите корректный `DATABASE_URL`, например:
  `postgresql+asyncpg://user:password@localhost:5432/botshop`
